# Chess

A browser-based chess game with a strong AI engine.

## How to play

Open `index.html` in any web browser — no server or install needed.

## Features

- Full legal move generation (castling, en passant, pawn promotion, check/checkmate/stalemate)
- AI opponent using minimax with alpha-beta pruning
- Three difficulty levels: Easy (depth 2), Medium (depth 3), Hard (depth 4)
- **Hint button** — shows the best move for your current position
- Visual highlights: selected piece, valid moves, last move, king in check
- Move history, evaluation bar, and captured pieces display
